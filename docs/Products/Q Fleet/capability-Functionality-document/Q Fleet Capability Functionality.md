
# Admin Login 

## Document Purpose 

This document describes the capabilities and functionality of the Fleet Management System for Group Motor insurance policies. The system enables organizations to purchase and manage insurance for multiple vehicles through an integrated digital platform. 

## System Overview 

The Fleet Management System provides end-to-end functionality for purchasing Group Motor insurance policies. The system supports both small and large fleet operations, offering flexible data entry methods and comprehensive vehicle management capabilities. 

# Login Page 

**Login Page and OTP Validation** 

The application uses an OTP (One-Time Password) system to keep your account secure. OTP verification is required during registration and every login. 

 

**OTP Validation During Registration** 
**New User Registration**
- Separate OTPs are sent to your email ID and mobile number. 
- You must verify both OTPs to complete registration. 
- This step improves security during account creation. 

 

**After Registration**

- A single OTP is used for both email and mobile verification. 
- This makes future logins and transactions faster and easier. 

**OTP Security Rules** 
**Invalid OTP Attempts** 
- You can enter the wrong OTP only a limited number of times. 
- If you enter an incorrect OTP multiple times, OTP entry is temporarily blocked. 
- This prevents unauthorized access. 

**OTP Resend Limit** 
- You can request to resend the OTP only a limited number of times within a short period. 
- If you reach the limit, you must wait before requesting a new OTP. 
- This helps prevent misuse of the OTP system.
