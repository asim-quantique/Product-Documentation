# Pickup and Drop Admin Actions
# 1.	Log in Admin Portal
To access the portal, follow these steps:
1)	Open your web browser, enter the Pickup and Drop URL in the address bar, and then press Enter.  ![](/img/products/transit-secure/admin/image1.jpeg)

- The Admin login page appears. ![](/img/products/transit-secure/admin/image2.png)

2)	Enter your email or mobile number and password, and then select Login. ![](/img/products/transit-secure/admin/image3.png)

- The verification page appears with OTP has sent success message.   ![](/img/products/transit-secure/admin/image4.png)

**Note: -** *You will receive an OTP on your registered phone number and email address. Enter the OTP to continue.*

3)	Enter the OTP, and then select Verify.  ![](/img/products/transit-secure/admin/image5.png)


- After successfully logging in, the Super Admin dashboard page appears.   ![](/img/products/transit-secure/admin/image6.png)

# 2.	Super Admin Dashboard Overview

Use the Transaction Approvals page to review and manage dealer deposit requests.

This page helps you:

- View all transaction requests 
- Review dealer bank transaction details 
- Check transaction status 
- Approve or refer back requests
- Track deposit requests and approvals 

The table displays the following details:

- **Sr. No:** Serial number 
- **Transaction Number:** Unique transaction reference number 
- **Bank Name:** Dealer bank name 
- **Branch Name:** Dealer bank branch 
- **IFSC Code:** Bank IFSC code 
- **Account Holder Name:** Name of the account holder 
- **Bank Account Number:** Dealer bank account number 
- **Account Type:** Bank account type (Current or Savings) 
- **Amount:** Deposit amount 
- **Transaction Type:** Type of transaction (for example, Deposit) 
- **Dealer Name:** Dealer name 
- **Dealer Code:** Unique dealer code 
- **Company Name:** Dealer company name 
- **Dealer Comment:** Comment added by the dealer 
- **Admin Comment:** Comment added by the admin 
- **Request Created At:** Request creation date 
- **Transaction Date:** Deposit transaction date 
- **Status:** Current request status (Pending, Approved, or Referback) 
- **Actions:** Option to view transaction details
