## 1.	Dealer Reset Password
Use this process to reset your password during the first sign-in.

- **Note: -** *After the dealer is register, the system sends a welcome email with the Username and a temporary password. You must reset the password during the first sign-in.*  ![](/img/products/transit-secure/dealer/image1.png)

- After you receive the email, note the **Login URL**, **username**, and **temporary password**. Use the Login URL to sign in and reset your password.

**Reset your password:**

1)	Open your web browser, enter the Login URL in the address bar, and then press **Enter**.  ![](/img/products/transit-secure/dealer/image2.jpeg)

- The **Dealer login** page appears.     ![](/img/products/transit-secure/dealer/image3.png)

2)	Enter your **username** and **temporary password**, and then select **Login**.   ![](/img/products/transit-secure/dealer/image4.png)

- The **OTP verification** page appears.    ![](/img/products/transit-secure/dealer/image5.png)

3)	Enter the OTP, and then select **Verify**.    ![](/img/products/transit-secure/dealer/image6.png)

- The **Reset your password** page appears.    ![](/img/products/transit-secure/dealer/image7.png)

**Note: -** *You must reset your temporary password after OTP verification.*

4)	Enter a **new password**, confirm it, and then select **Change Password**.      ![](/img/products/transit-secure/dealer/image8.png)

- **Result:** The system shows a confirmation message and redirects you to the **Login** page.  ![](/img/products/transit-secure/dealer/image9.png)


### 1.1	Log in as Dealer

1)	Enter your username and new password, and then select **Login**.   ![](/img/products/transit-secure/dealer/image10.png)

- The verification page appears with OTP has sent success message.   ![](/img/products/transit-secure/dealer/image11.png)

**Note: -** *You will receive an OTP on your registered phone number and email ID.*

2)	Enter the OTP, and then select **Verify**.   ![](/img/products/transit-secure/dealer/image12.png)

- After successfully logging in, the Dealer dashboard page appears.   ![](/img/products/transit-secure/dealer/image13.png)

## 3.	Driver Registration

Use this feature to onboard new drivers into the system.

1)	From the application's left-side menu, select Driver.    ![](/img/products/transit-secure/dealer/image29.png)

- The **Driver List** page appears.     ![](/img/products/transit-secure/dealer/image30.png)

2)	Select **Add Driver** in the upper-right corner. ![](/img/products/transit-secure/dealer/image31.png)

- The Add Driver dialog box appears.  ![](/img/products/transit-secure/dealer/image32.png)

3)	Select one onboarding method:
- **Bulk Upload**
- **Add Single Driver**  ![](/img/products/transit-secure/dealer/image33.png)
 

### 3.1	Bulk Upload

1)	Select Bulk Upload.  ![](/img/products/transit-secure/dealer/image34.png)

- The bulk upload section appears.  ![](/img/products/transit-secure/dealer/image35.png)

2)	Select Click Here next to To download sample.  ![](/img/products/transit-secure/dealer/image36.png)

3)	Open the Excel file and enter details for all driver.  ![](/img/products/transit-secure/dealer/image37.png)
Save the updated file.

4)	Select **Click to Upload** or drag and drop the file.   ![](/img/products/transit-secure/dealer/image38.png)

5)	Upload a valid **.xlsx** file (maximum size: 5 MB).     ![](/img/products/transit-secure/dealer/image39.png)

6)	Select **Submit**. ![](/img/products/transit-secure/dealer/image40.png)
The system uploads the file and adds the drivers

- A **Drivers uploaded successfully** message appears. The system then redirects you to the **Driver List** page.  ![](/img/products/transit-secure/dealer/image41.png)

- **View Icon (Eye):** In the Actions column, select the **View (eye)** icon to open the driver details page.   ![](/img/products/transit-secure/dealer/image58.png)
 

- **Driver Status:**
    - **Active:** The driver is active and can use the system. 
    - **Inactive:** The driver is not active.

     ![](/img/products/transit-secure/dealer/image59.png)
 

## 4.	Request Management
1)	From the menu, select **Request Management**.  ![](/img/products/transit-secure/dealer/image60.png)

- The **Request Management** page appears.   ![](/img/products/transit-secure/dealer/image61.png)

2)	Select **Add Request** in the upper-right corner.   ![](/img/products/transit-secure/dealer/image62.png)

- The **Add Request** page appears.  ![](/img/products/transit-secure/dealer/image63.png)

3)	In the Trip Type section, select one of the following options:
- **Pick-Up From Customer**
- **Pick-Up From Dealer**    ![](/img/products/transit-secure/dealer/image64.png)


4)	In the **Customer Details** section, enter the following information:
- **Full Name**
- **Mobile Number**
- **Email Address**      ![](/img/products/transit-secure/dealer/image65.png)
 

5)	In the address section, enter the required address details based on the selected trip type.    ![](/img/products/transit-secure/dealer/image66.png)


6)	In the **Dealer Address** section, select the **Same as Dealer Address** checkbox.    ![](/img/products/transit-secure/dealer/image67.png) 
The system automatically fills the dealer address fields with the registered dealer information. 

    Verify the auto-populated details before submitting the request.

7)	If the Same as Dealer Address checkbox is not selected, enter the dealer address details manually in the required fields.     ![](/img/products/transit-secure/dealer/image68.png) 

8)	In the **Vehicle Details** section, enter the following information:
- **Registration Number**
- **Vehicle Make**
- **Vehicle Model**
- **Vehicle Variant** 
- **Chassis Number**    ![](/img/products/transit-secure/dealer/image69.png) 
 

9)	In the **Trip Details** section, enter the following information: 
- **Trip Date and Time** 
- **Estimated Trip Duration**  ![](/img/products/transit-secure/dealer/image70.png) 
 
 
10)	Select Submit to create the request.  ![](/img/products/transit-secure/dealer/image71.png) 

    A success message appears after the request is created successfully.

### 4.1	Filter and Search Actions

Use the following options on the Request Management page to find records:

- **Add Request:** Select Add Request to create a new pickup or drop request. 
- **Search field and Search box:** Enter a value (for example, Trip Code, Customer Name, Vehicle Registration Number, Mobile Number, or Driver Name). The table updates to show matching results. 
- **Date Range:** Select a date range and then select Search to filter requests by created date or trip date. 
- **Clear Filter (Reset):** Clear the search and date filters to reset the list. 
- **Actions:** Use the Actions column to view request details and related information. 
- **Download Certificate:** Download the generated insurance certificate for the request. 
- **Transit Report:** View or download the transit-related report for the request. 
- **Status:** View the current status of each request. The status helps track the request progress in the system.

- View all dealer transaction records 
- Track wallet credit transactions 
- Review bank transaction details 
- Monitor dealer wallet balance 
- Verify transaction amounts and bank information
 
The table displays the following details:
- **Sr. No:** Serial number 
- **Transaction Number:** Unique transaction reference number 
- **Trip Code:** Related trip reference code 
- **Bank Name:** Dealer bank name

- **IFSC Code:** Bank IFSC code 
- **Bank Account Number:** Dealer bank account number 
- **Account Holder Name:** Name of the account holder 
- **Gross Balance:** Available wallet balance after the transaction 
- **Created At:** Transaction creation date
