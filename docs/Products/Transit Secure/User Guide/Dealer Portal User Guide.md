Use this process to reset your password during the first sign-in.

Note: - After the dealer is register, the system sends a welcome email with the Username and a temporary password. You must reset the password during the first sign-in.
 

After you receive the email, note the Login URL, username, and temporary password. Use the Login URL to sign in and reset your password.

Reset your password:
1)	Open your web browser, enter the Login URL in the address bar, and then press Enter.

2)	Enter your username and temporary password, and then select Login.

3)	Enter the OTP, and then select Verify. 

The Reset your password page appears. 

Note: - You must reset your temporary password after OTP verification.

4)	Enter a new password, confirm it, and then select Change Password. 

Result: The system shows a confirmation message and redirects you to the Login page.

4.	Request Management
1)	From the menu, select Request Management. 

The Request Management page appears. 

2)	Select Add Request in the upper-right corner. 

The Add Request page appears. 

3)	In the Trip Type section, select one of the following options:
•	Pick-Up From Customer
•	Pick-Up From Dealer

 

4)	In the Customer Details section, enter the following information:
•	Full Name
•	Mobile Number
•	Email Address
 

5)	In the address section, enter the required address details based on the selected trip type. 


6)	In the Dealer Address section, select the Same as Dealer Address checkbox. 
The system automatically fills the dealer address fields with the registered dealer information.

Verify the auto-populated details before submitting the request.

7)	If the Same as Dealer Address checkbox is not selected, enter the dealer address details manually in the required fields. 

8)	In the Vehicle Details section, enter the following information:
•	Registration Number
•	Vehicle Make
•	Vehicle Model
•	Vehicle Variant 
•	Chassis Number
 

9)	In the Trip Details section, enter the following information: 
•	Trip Date and Time 
•	Estimated Trip Duration
 

10)	Select Submit to create the request. 

A success message appears after the request is created successfully.

4.1	Filter and Search Actions
Use the following options on the Request Management page to find records:
•	Add Request: Select Add Request to create a new pickup or drop request. 
•	Search field and Search box: Enter a value (for example, Trip Code, Customer Name, Vehicle Registration Number, Mobile Number, or Driver Name). The table updates to show matching results. 
•	Date Range: Select a date range and then select Search to filter requests by created date or trip date. 
•	Clear Filter (Reset): Clear the search and date filters to reset the list. 
•	Actions: Use the Actions column to view request details and related information. 
•	Download Certificate: Download the generated insurance certificate for the request. 
•	Transit Report: View or download the transit-related report for the request. 
•	Status: View the current status of each request. The status helps track the request progress in the system.

5.1	Transaction Requests
1)	From the menu, select Bank, and then select Transaction Requests. 

The Transaction Requests page appears. 

2)	Select Add Transaction in the upper-right corner. 

The Add Bank Transaction page appears. 

Bank Account Details
3)	Verify the auto-populated account details:
•	Account holder name, account number, IFSC code, bank name, branch name, and account type.
 

Note: - The system automatically fetches the bank details based on the registered account information.

Transaction Details
4)	Enter the following transaction details:
•	Transaction number, deposit amount, transaction date, remarks. Upload the payment proof document.
 

Bank Details
5)	View the Quantique bank details displayed on the right side of the page:
•	Beneficiary name, bank name, branch name, account number, IFSC code.
 

6)	Use the QR code under Scan to Pay to make the payment, if required. 

7)	Select Submit. 

A confirmation dialog box appears. 
Review the transaction amount and confirmation message.

8)	Select one of the following options:
•	Confirm: Submit the transaction request.
•	Cancel: Close the dialog box without submitting the request.
 

A Deposit request raised successfully message appears. The system then redirects you to the Transaction Requests page. 

The transaction request status appears as pending. 

The system submits the request to the Super Admin for review and approval.
For more information about the deposit approval process, see Super Admin User Guide > Transaction Approvals > Transaction.

After the Super Admin approves the request, the transaction request status changes to Approved in the Dealer Transaction Requests table.

6.1	Theme Studio Overview
Use the Theme Studio page to customize the application appearance and color theme.
Theme Studio allows you to:
•	Select a predefined theme 
•	Customize primary and secondary colors 
•	Preview theme changes in real time 
•	Reset the theme settings 

The page contains the following sections:
•	Quick Themes 
•	Live Preview 
•	Custom Colors 
•	Reset Option 

Quick Themes
Use the Quick Themes section to apply predefined color themes.
The available themes include:
•	Amber Night 
•	Ocean Depth 
•	Forest Glow 
•	Crimson Pulse 
•	Nebula 
•	Sunset Blaze 
•	Cyber Neon 
•	Rose Quartz 

Each theme contains:
•	A primary color 
•	A secondary color 
•	A preview of the theme appearance
 

To apply a theme, follow these steps:
1)	In the Quick Themes section, select a theme. 
The selected theme is highlighted.

2)	View the updated design in the Live Preview section. 
The preview displays the updated colors and dashboard appearance in real time.

3)	Select Save Theme. 

A theme saved successfully message appears. 

The system applies the selected theme across the application interface.

Live Preview
Use the Live Preview section to view theme changes in real time.
The preview panel displays:
•	Navigation layout 
•	Dashboard cards 
•	Charts and widgets 
•	Primary and secondary colors 

The preview updates automatically when you:
•	Select a theme 
•	Change custom colors 
This helps you review the appearance before using the theme across the application.
 

Custom Colors
Use the Custom Colors section to create a custom theme.
The section contains:
•	Primary Color 
•	Secondary Color

Each color setting includes:
•	Color picker icon 
•	Hex color code field
•	Color preview bar
 

Change the Primary Color
To change the primary color, follow these steps:
1)	In the Primary Color section, select the color picker icon. 
Select a color.

2)	Alternatively, enter a valid hex color code in the color field. 
Example: #FFC107
The system updates the primary color automatically.

Change the Secondary Color
To change the secondary color, follow these steps:
1)	In the Secondary Color section, select the color picker icon. 
Select a color.

2)	Alternatively, enter a valid hex color code in the color field. 
Example: #1A1A1A
The system updates the secondary color automatically.

Reset Theme Settings
Use the Reset option to restore the default theme settings.
To reset the theme, follow these steps:
1)	Select Reset in the upper-right corner. 
The system restores the default theme colors and settings.
